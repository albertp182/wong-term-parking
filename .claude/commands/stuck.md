# Stuck Mode

The user is stuck, frustrated, or confused. Priority #1: get them unstuck and feeling good.

## Steps

1. **Acknowledge**: "No worries, let's figure this out."

2. **Diagnose**: Check these things in order:
   - Is there an error? → Read it, explain in plain English, fix it
   - Did a build fail? → Check the build output, find the issue
   - Is the simulator not working? → Check if Xcode/simulator is running
   - Is something not showing up? → Check the view hierarchy, data flow
   - Are they confused about what to do next? → Suggest next steps

3. **Fix it**: If possible, fix the issue directly. Explain what was wrong.

4. **If you can't fix it**:
   - "I'm not sure about this one. Let's save your work (/push) and ask Gustavo to take a look."
   - Never leave them hanging

5. **Prevent it**: After fixing, briefly explain what caused it so they can avoid it:
   - "This happened because [simple reason]. Next time, [simple prevention]."

## Tone
- Never blame them
- Never say "you should have..."
- Frame everything as "we" - "let's fix this", "we ran into..."
- Quick wins matter - fix the immediate problem first, explain later
