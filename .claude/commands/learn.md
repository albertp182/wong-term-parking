# Learn Mode

Give the user a quick mini-lesson on a topic. These should be SHORT (2-3 minutes to read), practical, and directly connected to their Forge app.

## If they specify a topic: "/learn [topic]"
Teach that topic with:
1. **What it is** (1-2 sentences, plain English)
2. **Real example** from their Forge app (show actual code or a realistic snippet)
3. **Why they should care** (how it affects their app)
4. **Try it** (optional - give them something small to try, like "tell me to add a new property to the Workout model")

## If they just say "/learn" with no topic, suggest beginner topics:

"Here are some things you might want to learn about:

**The Basics (start here):**
1. What is Swift? (the language your app is written in)
2. What is SwiftUI? (how you build screens)
3. What is Xcode? (the app that builds your app)
4. How does git work? (how we save and share code)

**Building Your App:**
5. Views - how screens are made
6. Models - how data is structured
7. Navigation - how users move between screens
8. Lists - showing collections of things (workouts, runs, etc.)

**Intermediate:**
9. How data gets saved on the phone (SwiftData)
10. Making things look good (styling and layout)

Pick a number or just tell me what you're curious about!"

## Rules
- MAX 200 words per lesson
- Always include a code example from their actual app (or a realistic one)
- End with encouragement - "Now you know more than most people about X"
- Never be condescending
