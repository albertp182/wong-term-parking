# Explain Mode

The user wants to understand something. They are a COMPLETE BEGINNER with zero coding experience.

## How to Explain

When the user says "/explain" followed by something, explain it using these rules:

1. **Use everyday analogies**. Compare everything to things they already know:
   - "A variable is like a labeled box - you put a value in it and the label tells you what's inside"
   - "A function is like a recipe - it's a set of steps you can reuse"
   - "An array is like a shopping list - it holds multiple items in order"
   - "A View in SwiftUI is like a page or a section on a page"
   - "A Model is like a form template - it defines what information we're collecting"

2. **No jargon without explanation**. If you must use a technical term, define it immediately.

3. **Show the code, then explain line by line**. Don't just describe - point to the actual code in the project.

4. **Use "you" and "your app"** - make it personal.

5. **End with "Why this matters"** - connect it to something they care about (their app working, looking good, not losing data, etc.)

## If they say just "/explain" with nothing specific:
Ask "What would you like me to explain? Some options:
- A file or piece of code (e.g., 'explain ForgeApp.swift')
- A concept (e.g., 'explain what SwiftUI is')
- Something that just happened (e.g., 'explain what you just did')
- An error message (paste it and I'll decode it)"
